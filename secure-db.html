API برای همه ماژول‌ها

از هر ماژول می‌توانید از طریق window.SmartDB (همین صفحه یا iframe/هم‌origin) فراخوانی کنید. نمونه کد:

// پس از باز شدن secure-db و Unlock
await SmartDB.put('sales', 'inv-1', {total:1000});
const row = await SmartDB.get('sales', 'inv-1');
const keys = await SmartDB.keys('sales');
await SmartDB.del('sales', 'inv-1');

برای استفاده واقعی بین صفحات هم‌origin، منطق در همین فایل است و می‌توانید آن را به smart-db.js جدا کنید. در نسخه تک‌فایل، عملیات از این پنل و از window.SmartDB در همین صفحه در دسترس است.
