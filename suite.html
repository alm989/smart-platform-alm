لاگ عملیات مرکز داده

قوانین فقط از فهرست امن ازپیش‌تعریف‌شده انتخاب می‌شوند. کاربر نمی‌تواند کد جاوااسکریپت دلخواه تزریق کند. موتور قوانین از eval / Function / اسکریپت پویا استفاده نمی‌کند.

افزودن قانون (اعلامی)

قوانین ذخیره‌شده

کنترل‌های فعال: CSP سخت · بدون object/frame بیرونی · بدون connect به API ثالث · بدون eval · قوانین اعلامی · ورود برای مغز و مرکز داده · لاگ عملیات حساس
محدودیت واقعی: هر کسی فایل‌های HTML را داشته باشد می‌تواند متن اسکریپت را ببیند. امنیت روی جلوگیری از تزریق، خرابکاری داده، و اجرای کد دلخواه تمرکز دارد.
