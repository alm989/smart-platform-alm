# نقشه امنیت — ادغام تدریجی بسته Auth گوگل‌درایو

## الان (سرور v1.1)
- ورود با user/pass/pin و توکن Bearer
- محدودیت نرخ ورود (۱۰ تلاش / دقیقه / IP+user)
- هدرهای `nosniff` و `Referrer-Policy`
- پشتیبان startup + روزانه + نگهداری ۳۰ روز
- داده ماژول‌ها: JSON فایل

| نشست در SQLite + revoke | بالا | فاز بعد |
